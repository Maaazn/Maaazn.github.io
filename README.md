# On Web Development — Root Site

This static site is the public-facing fieldbook for verified protocol research. It intentionally separates **proved transport** from device pairing and account workflows that have not been tested on a device.

The local WebSocket-to-TCP transport proof lives in [Maaazn/on-web-development](https://github.com/Maaazn/on-web-development). No credentials, certificates, IPA files, pairing files, or account flow are included here.
