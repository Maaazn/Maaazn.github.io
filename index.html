كاشِف / KashifWeb — مراجعة مصدر محلية

افهم صفحة الويب قبل أن تنشرها.

كاشف أداة مراجعة تعمل داخل المتصفح. تقرأ HTML وCSS اللذين تختارهما على جهازك، ثم تعرض أدلة قابلة للمراجعة حول العربية وRTL والبيانات الوصفية وبنية الصفحة والإتاحة الأساسية. لا نطلب حساباً، ولا نرفع الكود الذي تلصقه إلى خادم كاشف.

ما الذي نراجعه فعلاً؟

نبحث في المصدر عن إشارات محددة، مثل لغة المستند واتجاهه، عنوان الصفحة ووصفها وcanonical وviewport، تسلسل العناوين، بدائل الصور، أسماء الحقول، وبعض أنماط CSS التي قد تربك النص العربي. كل نتيجة تربط قاعدة بدليل وسبب وخطوة مراجعة، بدلاً من إعطاء رقم مجرد أو وعد عن ترتيب البحث.

كيف تستخدم التقرير؟

  1. الصق HTML أو حمّل ملف الصفحة الذي تريد مراجعته.
  2. أضف CSS منفصلاً عندما تريد مراجعة إشارات الاتجاه والخصائص المنطقية.
  3. راجع الدليل والاقتراح، ثم أصلح المصدر واختبر الصفحة المنشورة على الهاتف وسطح المكتب.
  4. احفظ تقريراً محلياً أو صدّر خطة إصلاح Markdown لتوثيق ما تغير.

حدود لا نخفيها

كاشف لا ينفذ JavaScript الخاص بالصفحة التي تراجعها، ولا يتجاوز CORS، ولا يزحف الويب، ولا يقيس Core Web Vitals، ولا يضمن SEO أو قبول إعلان أو امتثالاً قانونياً. النتيجة دليل أولي يساعدك على بدء المراجعة، وليست شهادة خارجية.

محتوى للمطور قبل أي درجة

الصفحة العربية المفيدة لا تكتفي بـlang="ar": اتجاه النص، ترتيب العناوين، النصوص البديلة، التحكم بالتركيز، وخصائص CSS المنطقية كلها تؤثر في قابلية القراءة والمراجعة. كما أن وجود عنوان لا يثبت أنه مناسب؛ لذلك يميز كاشف بين غياب الإشارة وبين إشارة تحتاج قراراً تحريرياً من صاحب الصفحة.

عندما يتعذر فحص رابط عام، فهذا لا يعني بالضرورة أن الموقع متوقف. غالباً تمنع سياسة CORS المتصفح من قراءة الاستجابة. لهذا يبقى إدخال المصدر أو الملف المسار الأكثر موثوقية في هذه الأداة المحلية.

الخصوصية والمنهجية

ستجد داخل التطبيق المنهجية الكاملة وسياسة الخصوصية والشروط والتواصل. بعد تحميل التطبيق، تظهر غرفة المراجعة والأدلة الأصلية وخطة الإصلاح ومساحة المقارنة الاختيارية بوضوح.

عن الناشر

ينشر Maaazn كاشف كمشروع مستقل للمطورين ومالكي المواقع الذين يريدون مراجعة مصدر الصفحة قبل نشره. هدف المشروع هو توضيح ما يمكن استنتاجه من المصدر وما لا يمكنه إثباته، وليس دفع المستخدم إلى شراء أو ادعاء قبول من أي منصة خارجية. للتواصل أو الإبلاغ عن خطأ في قاعدة، استخدم رابط التواصل داخل التطبيق.
