# Security

لا تنشر مفاتيح أو ملفات مستخدمين أو HTML خاصاً في issue عام. استخدم **Report a vulnerability** في GitHub أو وسيلة الاتصال الخاصة التي يحددها مالك المستودع.

Do not publish secrets, user files, or private HTML in a public issue. Use GitHub **Report a vulnerability** or the repository owner’s stated private contact channel.
