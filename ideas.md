# On Web Development — Root Site Design

## Chosen approach: Protocol Fieldbook

**Design movement:** Editorial technical field notes with restrained industrial interface cues.

**Core principles:** Evidence precedes claims; every status has a defined boundary; the reading path follows protocol gates rather than marketing sections; the interface feels like a carefully labeled technical instrument.

**Color philosophy:** Warm bone paper offsets deep graphite and near-black; an electric blue marks proven transport, a restrained copper marks work still requiring a real device. The colors communicate state rather than decoration.

**Layout paradigm:** An asymmetric fieldbook spine runs down the left, while protocol evidence panels cascade to the right. The hero is not centered; it begins as a labeled system specimen.

**Signature elements:** Gate coordinates (`G0–G7`), thin diagnostic rules, mono status tags and a digest strip for verifiable output.

**Interaction philosophy:** Controls reveal context and evidence, not artificial success. State changes are local and visibly bounded.

**Typography system:** `DM Mono` for protocol data and `Space Grotesk` for headings. English stays LTR; Arabic content uses a dedicated RTL block.

**Brand essence:** On Web Development documents and tests the difficult boundary between browser transport and device-local development workflows. Precise, candid, methodical.

**Brand voice:** “Transport proven. Device pairing remains a separate gate.” / “No credential flow is enabled in this build.”

**Wordmark & logo:** A stacked `ON / WEB` wordmark with a single open bridge glyph made from two discontinuous lines.

**Signature brand color:** Evidence Blue `#1B74FF`.
